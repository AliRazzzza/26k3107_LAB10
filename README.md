# Post Lab 10

## Tasks

1. **Student Information:** Find a name's length, copy it, and add `" - FAST University"` to it.
2. **Product Comparison:** Compare two product names and display their lengths.
3. **Character Search:** Find the first occurrence of a character in a sentence and copy the sentence.
4. **Student Names:** Store five names in a 2D character array, display their lengths, and search for a character.
5. **Student Result:** Calculate a percentage, save the result to a file, and read it back.
6. **Bank Transactions:** Save a transaction, append another transaction, and display both records.
7. **Update Marks:** Read existing marks from a file and update them.
8. **Result Processing:** Write and read a student's result using `w+` mode.

## Primary focus

- Using 1D and 2D character arrays.
- Working with `strlen()`, `strcpy()`, `strcat()`, `strcmp()`, and `strchr()`.
- Opening and closing files using `fopen()` and `fclose()`.
- Writing and reading data using `fprintf()` and `fscanf()`.
- Using file modes `w`, `r`, `a`, `r+`, and `w+`.
- Moving back to the beginning of a file using `rewind()`.
